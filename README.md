# PPRO

Projektový repozitář pro **PPRO** (Pokročilé programování).

---

## 📌 O projektu
Tento repozitář slouží ke správě zdrojových kódů, úkolů a dokumentace v rámci projektu **PPRO**.

## 🚀 Rychlý start

### Klonování repozitáře
```bash
git clone https://github.com/MichalBleha/PPRO.git
cd PPRO
```

### Práce s projektem
1. Vytvořte novou větev pro danou funkcionalitu či úkol:
   ```bash
   git checkout -b feature/nazev-funkce
   ```
2. Proveďte změny a vytvořte commit:
   ```bash
   git add .
   git commit -m "Popis změn"
   ```
3. Nahrajte změny do vzdáleného repozitáře:
   ```bash
   git push origin feature/nazev-funkce
   ```
